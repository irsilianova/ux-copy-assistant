# Links

## Definition

A link takes someone to a destination, such as a page, a document, or a section on the current page. Its text should help them predict what they’ll find when they follow it.

## Core technique

Read the link as the answer to “Where will this take me?” The bold words are the link text.

| Intent | Sentence frame | Example |
| --- | --- | --- |
| Name a destination | This takes me to [page or resource]. | In account navigation, **Billing history**. |
| Open a specific item | I want to [verb + object]. | Beside an order, **View receipt**. |
| Explain a topic in context | I can find out [what I’ll learn]. | In a paragraph about returns, “See **how refunds work**.” |

Then read only the linked words. **How refunds work** still tells someone what they’ll learn. **Here** makes them go back and reconstruct the sentence.

## Language rules

### Allowed

- **Destination names.** Use the page or document name when people will recognize it. **Delivery areas** works both as a standalone link and in “Check our **delivery areas**.”
- **A verb when it clarifies the destination.** **Compare plans** tells someone why they might open a comparison page. **View invoice** works when the destination is an invoice they can read.
- **Natural inline wording.** Link the smallest phrase that still identifies the destination. In “Read the **cancellation policy** before you book,” the document name carries the meaning.

### Avoid

- **Generic link text.** Replace **Click here**, **More**, or a standalone **Learn more** with the topic someone is opening. **How pricing works** gives them a reason to follow the link.
- **Labels that promise a different outcome.** **View invoice** should open an invoice. If following the link immediately downloads a file, use **Download invoice**.
- **Links for changes to the user’s data.** **Notification settings** can link to a settings page. If selecting **Save changes** applies the settings, write it as a button action.

### Use with caution

- **Repeated links.** Three links called **View details** are hard to distinguish. If the destinations differ, name them: **Plan details**, **Payment details**, **Delivery details**.
- **Several links in one sentence.** If someone needs to compare destinations, a short list of clearly named links is easier to scan and translate.
