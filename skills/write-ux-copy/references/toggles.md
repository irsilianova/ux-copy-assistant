# Toggles

## Definition

A toggle controls one setting with two states, on and off. The change takes effect as soon as someone flips the switch. Each toggle should work independently. If people need to choose one option from a set, use radio buttons. If they can select several before applying their choices, use checkboxes.

## Core technique

Read the label as part of a sentence someone might actually say. Try these three frames and look for one that makes sense for the setting. The bold words are the label.

| Sentence frame | Example |
| --- | --- |
| I want to see [label]. | I want to see **places nearby**. |
| I want to make [this object] [label]. | I want to make my playlist **private**. |
| I want to switch on [label]. | I want to switch on **quiet hours**. |

For a label that already starts with a verb, use the shorter frame “I want to [label].” For example, “I want to **show captions**.” In every case, check that the sentence describes what happens when the switch is on.

## Language rules

### Allowed

- **Nouns and short noun phrases** can name a setting directly. Examples include “Dark mode,” “Email reminders,” and “Quiet hours.”
- **Affirmative verbs** work when the action is easier to recognize than the setting name. Use wording like “Show captions” or “Save my place.”
- **Short descriptive phrases** work when a single noun leaves out a detail that matters. On a search screen, “Places open now” tells people exactly which results they’ll see.

### Avoid

Avoid labels that describe what the switch disables, hides, stops, removes, or blocks. “Hide captions” makes someone work out that switching it off will show captions. Use “Show captions” for a switch whose on state displays them. If you reverse the wording of an existing label, check that the switch state matches the new wording.

### Use with caution

- **Longer phrases.** Keep details that change the meaning of the setting. In a list of events, “Events near me” says as much as “Events happening close to where I am.”
- **Standalone adjectives.** “Private” works next to a playlist title when it’s clear which playlist the switch affects. In a list of account settings, name the object too, as in “Private profile.”
