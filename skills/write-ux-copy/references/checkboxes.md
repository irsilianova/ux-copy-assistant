# Checkboxes

## Definition

A checkbox lets someone select an option or leave it unselected. In a group, people can choose several options together. A standalone checkbox can express a preference or confirm agreement. If choosing one option rules out the others, use radio buttons.

## Core technique

Read each label as something a person might choose, say, or agree to. The bold words are the checkbox label.

| Intent | Sentence frame | Example |
| --- | --- | --- |
| Choose an item | I’d like [checkbox label]. | I’d like **extra cheese**. |
| Filter results | Show me places with [checkbox label]. | Show me places with **outdoor seating**. |
| Opt in | Please [checkbox label]. | Please **email me a copy**. |
| Confirm agreement | By checking this box, I’m saying “[checkbox label].” | By checking this box, I’m saying “**I agree to the booking terms**.” |

For a group, read the heading on its own first. **What’s missing from your order?** makes sense before anyone sees the choices. Then read the options together. **Fries**, **Dipping sauce**, and **Drinks** all answer the same question, and someone can select any combination.

## Language rules

### Allowed

- **A heading that stands on its own.** Name the category (**Pizza toppings**), give a short instruction (**Choose your toppings**), or ask a question (**What would you like on your pizza?**). An existing section heading can do this job if it clearly applies to the whole group.
- **Parallel options.** Use nouns, phrases, or short sentences. Keep the same grammatical pattern across a list. Under **How should we reach you?**, **Email** and **Text message** work as a pair.
- **Affirmative wording.** Describe what checking the box means. **Send me weekly tips** gives someone a clear way to opt in. For a standalone agreement, name what the person accepts, as in **I agree to the booking terms**.
- **Sentence case and minimal punctuation.** Use a question mark when the group heading asks a question. Leave end punctuation off checkbox labels. If the group needs a full sentence of explanation, put it below the heading and punctuate it normally.

### Avoid

- **Headings that depend on the options to finish a sentence.** **Send updates by** leaves the thought unfinished and can be awkward to translate. **How should we send updates?** works on its own.
- **Negative opt-ins.** A label like **Don’t send me weekly tips** makes someone work out what leaving the box empty means. When changing it to **Send me weekly tips**, make sure the checked state actually opts the person in.
- **Repeating the heading in every option.** Under **Which days work for you?**, use **Monday** and **Tuesday**. The heading already supplies “works for me.”

### Use with caution

- **Long labels.** Aim for one or two words when naming an item. Use more when they clarify a choice or commitment. If the full label needs a second line, let it wrap. An ellipsis can hide the detail someone needs to decide.
- **Selection instructions.** Add **Choose all that apply** when people might reasonably assume they can pick only one. Put it with the group heading so it applies to every option.
- **Hidden labels.** A checkbox in a table row may have enough visible context. Give it an accessible name that identifies the item, such as **Select Saturday’s booking**, so someone using a screen reader can tell which booking they’re selecting.
