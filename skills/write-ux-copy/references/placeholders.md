# Placeholders

## Definition

A placeholder is a short hint inside an empty field. It can show a sample value, suggest what to write, or clarify what someone can search for. It usually disappears as soon as someone starts typing, so the field label and any essential instructions need to stay visible.

## Core technique

Read the label first. What might someone still wonder before they start typing? Use the placeholder to answer that question. The bold words are the placeholder text.

| Intent | Sentence frame | Example |
| --- | --- | --- |
| Show a sample value | An entry might look like [example]. | **Playlist name** → **e.g., Sunday mornings** |
| Suggest what to write | One useful detail I could leave is [example]. | **Delivery notes** → **e.g., Ring the upstairs bell** |
| Clarify search scope | I can search by [supported criteria]. | **Search contacts** → **Name, email, or phone number** |

Then imagine the field with a value in it. Once the placeholder disappears, can someone still tell what the field is for and how to complete it correctly?

## Language rules

### Allowed

- **One realistic example.** Choose something short enough to scan and representative of a valid entry. For **Order number**, **e.g., AB-12345** shows the expected shape.
- **A hint that adds to the label.** Under **Search files**, **File name or owner** helps someone discover a second way to search. Mention only criteria the product supports.
- **An empty field.** If **First name** tells someone everything they need, leave the placeholder blank.

### Avoid

- **Repeating the label.** **Enter your first name** below **First name** adds words without answering a new question.
- **Rules that vanish during entry.** If a date must follow a specific format, keep that format in the label or helper text so people can refer to it while typing.
- **Text that looks like an existing value.** In a field labeled **Team name**, **Design team** could look like a name someone has already chosen. **e.g., Design team** makes its purpose clearer.

### Use with caution

- **Locale-specific examples.** A date like **04/05/2027** can mean April 5 or May 4. Match the example to the locale and the format the field actually accepts.
- **Prompts in open-ended fields.** A short question can help someone get started. For **Feedback**, **What could we make easier?** works when the team is specifically asking about friction. A broader request calls for a broader prompt.
