# Empty states

## Definition

An empty state explains why a page or section has nothing to show. The wording depends on what happened: someone is using a feature for the first time, a search found no matches, they cleared the last item, or the content couldn’t load.

## Core technique

Start with the question someone is likely to ask when they see the empty space. Answer it in the heading. Use the body to explain what belongs there or what they can do next. Add a button when the action is available from that screen.

| Intent | Sentence frame | Example |
| --- | --- | --- |
| Introduce an unused feature | No [items] yet. [How an item gets here]. | **No saved places yet** · Tap the bookmark on a place you’d like to visit. |
| Explain an empty result | No [items] match [criteria]. [What can I change?] | **No stays match your filters** · Try a wider price range or remove a filter. · **Clear filters** |
| Confirm that a queue is clear | [Task] is complete. [What happens next?] | **You’ve reviewed every request** · New requests will appear here. |
| Explain unavailable content | [Items] couldn’t load. [How can I recover?] | **Couldn’t load your bookings** · **Try again** |

Before writing **No bookings yet**, check what the product actually knows. A successful request that returns zero bookings supports that heading. A failed request calls for **Couldn’t load your bookings**. The distinction matters to someone who remembers making a reservation.

## Language rules

### Allowed

- **Name what’s missing.** **No saved recipes yet** tells someone what belongs on the screen. If the feature is new to them, explain how the first item gets there.
- **Give the most useful next step.** If people can create a list here, offer **Create a list**. If lists arrive from a teammate, explain **Lists your team shares with you will appear here**.
- **Let a completed task feel complete.** After someone reviews the last request, **You’ve reviewed every request** can stand on its own. They can leave the screen confident they’re done.

### Avoid

- **Generic headings.** **Nothing here** could describe an unused feature, an unsuccessful search, or a loading problem. Name the state you can verify.
- **Restating the heading in the body.** Under **No drafts yet**, “You don’t have any drafts” adds nothing. Use that space to explain how drafts are saved, if that would help.
- **First-use copy after a search.** Someone who sees no results for “linen” needs a way to change the search. An invitation to add their first product suggests their whole catalog is empty.

### Use with caution

- **“Yet.”** It fits when content is expected to appear, as in **No replies yet**. Under active filters, **No matching orders** is more precise.
- **“All caught up.”** Use it when the product can confirm the person has finished something. An empty inbox on a brand-new account is a different situation.
